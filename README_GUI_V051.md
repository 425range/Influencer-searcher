# v0.5.1 GUI 가독성 개선

기능 로직은 v0.5와 동일하고 GUI 색상/가독성만 개선했습니다.

주요 변경:
- 상단 Navy 헤더
- 분석 시작 버튼 Blue 강조
- 결과 Excel 버튼 Green 강조
- 입력 필드 White + Focus Blue border
- 포함 키워드: 옅은 Blue
- Hard 제외 키워드: 옅은 Red
- Soft 제외 키워드: 옅은 Orange
- 실행 로그: Dark console
- 탭 선택 상태 강조
- 버튼 padding 및 입력칸 padding 확대

실행:
`python gui.py`

또는 Windows에서 `run_gui.bat`
